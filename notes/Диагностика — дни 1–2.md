# Диагностика навыков — первые два дня

Старт: 29 сентября 2026 года. Обязательное время: 3 часа в день. Сначала выполнить задания самостоятельно, без coding agent; справочная документация допустима, но использованные подсказки нужно записать. После попытки разобрать код, ошибки и пробелы вместе.

## День 1 — React и TypeScript

1. **90 минут — практическое задание.** В отдельном worktree `lush-guesser` доработать `LeaderboardScreen`: явные состояния loading / empty / error / success, повторная загрузка после ошибки, отмена запроса при уходе со страницы. Старый ответ не должен перезаписывать более новый. Не выдавать тестовые записи за реальные данные при ошибке API. Существующие изменения в основной рабочей копии не переносить и не сбрасывать.
2. **35 минут — проверка.** Написать или обновить браузерные тесты хотя бы для успешной загрузки и для ошибки с повторной попыткой. Запустить доступные lint/build и эти тесты; записать фактический результат.
3. **25 минут — объяснение вслух.** Объяснить, зачем нужен cleanup эффекта, что произойдёт при быстром переключении экранов, как устроены состояния и почему ошибка API не равна пустой таблице.
4. **30 минут — поиск.** Сохранить три релевантные Frontend вакансии и записать для каждой требования и наличие или отсутствие указанной зарплаты. Отклики — по готовности представления кандидата.

## День 2 — Node.js и TypeScript

1. **90 минут — практическое задание.** Отдельно от приложения реализовать `mapLimit<T, R>(items, limit, worker)`: не более `limit` одновременных задач, результат в порядке входных элементов, корректное завершение при ошибке worker. Написать тесты для ограничения параллелизма, порядка результата и ошибки.
2. **45 минут — объяснение вслух.** Разобрать event loop, очередь microtasks, отличие `Promise.all` от ограниченной параллельности, поведение уже запущенных задач при ошибке и возможную поддержку `AbortSignal`.
3. **45 минут — поиск.** Найти ещё три вакансии Frontend/Fullstack и подготовить два адресных отклика, если материалы для отправки готовы.

## Результат диагностики

Для каждого задания записать фактическое время, использованные источники, результат команд проверки и то, что не удалось объяснить. **Green** — самостоятельное рабочее решение и ясное объяснение; **Yellow** — решение с подсказками или пробелами в объяснении; **Red** — нет рабочего результата. Оценка нужна для следующей недели, а не для резюме.
